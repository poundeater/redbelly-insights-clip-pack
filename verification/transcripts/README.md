# Full-episode machine transcripts

Machine transcripts (Whisper small.en) of the four most recent Redbelly Insights episodes, grouped into roughly 45-second paragraphs. Each paragraph starts with an `[m:ss]` timestamp. They were used to find and compare candidate moments, and they make it quick to check the source timestamps in `CLIP_LIST.md`.

These transcripts are **not proof-read**. Names and brand terms are often misheard (for example "Red Belly", "Akasha" for Acacia, "Tokenizer"). The proof-read text for each clip is in `clips.json` and `subtitles/`.
